# Changelog

Все значимые изменения документируются в этом файле.

## [0.1.0-alpha] - 2026-11-16
### Добавлено
- Инициализация проекта Godot 4.4.1, воксельная система (чанк 16³, sparse, face-culling + greedy).
- 5 инструментов: Кувалда «Удар-5», Терморез «Кромка», Заряд «Хлопок», Распылитель «Ингибитор», Проектор «Пролет».
- 2 машины: Кар «Муравей», Вездеход «Краб».
- 4 миссии + обучение + песочница, 3 локации (Завод, Порт, Купол).
- Физика разрушений, взрывов, огня/дыма, обрушений (BFS).
- Сенсорное управление (2 стика), настройки чувствительности, haptics toggle, поддержка геймпада.
- Локализация ru/en (100% ключей), профили качества Low/Medium/High/Auto.
- Сохранения, benchmark сцена, HUD с дебаг-статами.
- CI (GitHub Actions): тесты + сборка APK arm64-v8a, артефакты, Release.
- Документация: ARCHITECTURE, IMPLEMENTATION_PLAN, BUILD_ANDROID, QA_REPORT.

### Известные ограничения
- Транспорт — placeholder (статика в alpha).
- Физика обрушения упрощена.
- Требует тестирования на реальном устройстве.
