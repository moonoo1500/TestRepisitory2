# DOMINION: Осколки Ариона

Полноценная **3D-стратегия в реальном времени (RTS)** на Three.js: добыча ресурсов, строительство базы,
производство армии, туман войны, бой с таблицей типов урона и развивающийся ИИ-противник.
Без внешних ассетов — все модели, звуки и ландшафт генерируются кодом.

![стек](https://img.shields.io/badge/three.js-r180-black) ![vite](https://img.shields.io/badge/vite-6-646cff) ![тесты](https://img.shields.io/badge/tests-28%20passing-brightgreen)

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
```

Прочие команды:

| команда | что делает |
|---|---|
| `npm run dev` | dev-сервер с HMR |
| `npm run build` | production-сборка в `dist/` |
| `npm run preview` | раздача собранной версии |
| `npm test` | 28 headless-тестов игровой логики |
| `npm run sim` | автоплеер: прогон целых матчей для проверки баланса |

## Как играть

**Цель** — уничтожить все постройки и юнитов Роя Каоса раньше, чем он уничтожит ваши.

### Управление

| действие | клавиши |
|---|---|
| панорама камеры | `←↑↓→`, курсор к краю экрана, миникарта |
| зум к курсору | колесо мыши |
| поворот / наклон | средняя кнопка (тянуть), `Q` / `E` |
| выбор | ЛКМ, рамка, `Shift`/`Ctrl` — добавить, двойной клик — все того же типа |
| приказ | ПКМ по земле / врагу / кристальной жиле |
| атака в точку | `A` → цель |
| патруль | `P` → 2+ точки |
| стоп / держать позицию | `S` / `H` |
| группы | `Ctrl+1…9` назначить, `1…9` вызвать |
| вся армия | `Tab` |
| меню построек | `B` |
| пауза / справка / звук | `Esc`, `F1`, `M` |
| скорость игры | кнопка `1×` на верхней панели |

> `WASD` намеренно **не** отданы камере: `A` (атака) и `S` (стоп) — базовые команды RTS.

### Экономика

- **Кристаллы ◆** — сборщики «Муравей» возят их из жил в командный центр. Жилы истощаются.
- **Энергия ⚡** — реакторы дают мощность, постройки её потребляют.
  При дефиците производство, скорость юнитов и турели работают **на 42–100 %** — следите за жёлтой полосой.
- **Лимит армии** — `+14` за каждый командный центр. Упёрлись — стройте второй (это ещё и приёмный пункт кристаллов).

### Бой: камень-ножницы-бумага

| тип урона | силён против | слаб против |
|---|---|---|
| пуля (рейнджер, турель) | пехота | танки, авиация |
| ракета (лансер) | танки, **авиация** | пехота |
| пушка (бастион, мортира) | постройки, техника | авиация |
| ионный луч (хранитель, тесла) | всё понемногу, игнорирует броню | — |
| бомбы (серафим) | пехота, постройки | авиация |

По воздуху бьют только **лансер, хранитель, оса, турель и тесла** — без ПВО авиация противника безнаказанна.

## Юниты и постройки

**Юниты (8):** сборщик «Муравей», рейнджер, лансер, бастион, мортира, оса, серафим, хранитель.
**Постройки (10):** командный центр, казармы, завод тяжёлой техники, аэродром, технолаборатория,
реактор, оборонная турель, тесла-вышка, генератор щита, барьер.

Дерево технологий: `казармы → завод → аэродром → технолаборатория`.

### Технические детали

- **Туман войны** — 96×96 текстура, сэмплируется прямо во фрагментном шейдере ландшафта
  (внедрение через `onBeforeCompile`), поэтому корректно ложится на холмы.
  Перекрывающиеся зоны обзора только **повышают** уровень видимости — иначе они гасят друг друга.
- **Поиск пути** — A* по сетке 96×96 с octile-эвристикой, стоимостью рельефа (мелководье и заросли дороже)
  и «побегом» из занятой клетки: юнита, которого замуровали своей же постройкой, не клинивает.
- **Движение** — маршруты с формированием, локальное расталкивание через пространственный хеш,
  скольжение вдоль препятствий, наклон корпуса по склону, пыль из-под гусениц.
- **Модели** — собираются из примитивов и кэшируются по геометрии; анимируются ходьба, вращение башен,
  роторы, парение авиации, раскрытие ворот цеха, пульсация ядер реакторов.
- **Производительность** — ~1 мс на кадр логики при 200+ сущностях (медиана замера в headless-прогоне).

## Тесты

`npm test` гоняет настоящую игровую логику без браузера: WebGL-растеризация заменяется заглушкой,
а 2D-канвас (миникарта, туман войны) — настоящий (`@napi-rs/canvas`).

Проверяются: генерация трёх карт и связность баз, поиск пути и поле потока, сборка всех 18 моделей,
таблица урона, туман войны, полный 6-минутный матч (экономика, развитие ИИ, отсутствие NaN),
бой и гибель юнитов, ПВО, добыча кристаллов, условия победы и поражения, приказы и группы,
выбор кликом/рамкой, размещение построек, миникарта, экран результатов — **28 тестов**.

`npm run sim` запускает автоплеера, который играет целый матч по билд-ордеру, —
так проверяется баланс: длительность, соотношение сил и итог на каждой сложности.

## Сложность

| режим | доход ИИ | скорость постройки | размер волн | интервал волн |
|---|---|---|---|---|
| Разведка | ×0.85 | ×0.8 | ×0.7 | 150 с |
| Вторжение | ×1.0 | ×1.0 | ×1.0 | 125 с |
| Истребление | ×1.25 | ×1.3 | ×1.4 | 95 с |

Первая волна приходит примерно через `интервал × 1.55` — есть время развернуть оборону.
