# План реализации — КРОШЕВО: Протокол Демонтажа / SHATTERLINE

## 1. Концепция

**Рабочее название:** КРОШЕВО  
**Релизное название:** КРОШЕВО: Протокол Демонтажа / SHATTERLINE: Demolition Protocol  
**Сеттинг:** Постапокалиптический архипелаг — бывшая энерго-экспериментальная зона «Контур». Комплексы заброшены после инцидента, игрок — инженер-сальвагер, который извлекает ядра данных, спасает дроны и расчищает пути.  
**Жанр:** Физическая sandbox-головоломка от 1-го лица с разрушаемым воксельным миром.  
**Уникальность:** Оригинальные уровни, инструменты, транспорт, сюжетная рамка без заимствований.

### Локации (3)
- **Завод «Кристалл»** — бетон, металл, стекло. Вертикальная структура, мосты-краны.
- **Порт «Северный»** — контейнеры, склады, вода, краны.
- **Купол «Горизонт»** — научный комплекс, купол, лаборатории, полуразрушенный реактор.

### Кампания (4 миссии + обучение + песочница)
- **М0 Обучение: «Первый разрез»** — механика движения, ударов, резки, взрыва, постройки, тушения.
- **М1 Завод: «Ядро в цеху»** — найти 2 ядра, открыть ворота, эвакуироваться (15 мин подготовка, затем тревога 3 мин).
- **М2 Порт: «Контейнеры памяти»** — разблокировать кран, достать контейнеры, погрузить на платформу.
- **М3 Купол: «Тишина в куполе»** — пробоина в куполе, пожар, спасти дронов, отключить реактор.
- **М4 Финал: «Прорыв Контура»** — комбинированная локация, все инструменты, обрушение моста, таймер.
- **Песочница:** Открытая площадка 64×32×64 вокселей, все инструменты, спавн машин, без таймера.

### Инструменты (5)
1. **Кувалда «Удар-5»** — точечный урон, ломает слабые стены, отбрасывает предметы.
2. **Терморез «Кромка»** — луч, режет металл по линии, прожигает отверстия.
3. **Заряд «Хлопок»** — ставится, таймер 3с, сферический взрыв, разрушает в радиусе.
4. **Распылитель «Ингибитор»** — тушит огонь, охлаждает, временно укрепляет.
5. **Проектор «Пролет»** — создает временный воксельный мост/платформу на 30с.

### Транспорт (2)
- **Кар «Муравей»** — быстрый погрузчик, перевозит ящики, таранит слабые стены.
- **Вездеход «Краб»** — 4×4 с краном-манипулятором, поднимает тяжелые блоки, устойчив.

## 2. Техническая архитектура

### Движок
- Godot 4.4.1 stable, GDScript, Forward+ (Vulkan), fallback Compatibility (OpenGL).
- Single scene-tree, chunked voxel world как Node3D контейнер.

### Воксельная система
- Мир = словарь чанков `Dictionary[Vector3i -> VoxelChunk]`, размер чанка 16×16×16.
- Хранение: `PackedByteArray` для плотности + `Array` материалов, sparse (пустые чанки не создаются).
- Материалы: enum {AIR=0, CONCRETE=1, METAL=2, WOOD=3, GLASS=4, ROCK=5, BRICK=6} с полями прочность, воспламеняемость.
- Мешинг: face culling + greedy meshing per chunk, пересборка только dirty чанков.
- Коллизии: упрощённые `BoxShape3D`/`ConvexPolygonShape3D` агрегированные по слоям, не на воксель.
- Бюджет: max 64 активных RigidBody, 128 частиц, 32 декали.

### Физика разрушений
- Сфера разрушения: итерация вокселей в радиусе, проверка HP.
- Взрыв: Physics `apply_impulse` на nearby bodies, raycast для урона.
- Огонь: клеточный автомат по вокселям, распространение с шансом, дым как GPU particles.
- Обрушение: BFS граф связности к «земле», отделившиеся кластеры → RigidBody с ограниченным временем жизни + пул.

### Оптимизации
- Dirty flag + очередь пересборки, не более 2 чанков за кадр.
- Фоновые вычисления: BFS в thread, результат в main thread.
- Pooling для обломков, Decal, Particles.
- Frustum culling через VisibilityAABB, LOD (дальние чанки — упрощённый меш).
- Атлас материалов 1024×1024, один StandardMaterial.
- Лимиты: огонь ≤16 ячеек, дым ≤100 частиц, свет ≤8.
- Сохранение: JSON + RLE сжатие, версионирование.

### Android
- minSdk 24 (Android 7), targetSdk 34, arm64-v8a primary.
- Портрет заблокирован, landscape, обработка вырезов через safe area.
- Профили: Low/Medium/High/Auto (определяется по RAM/CPU).
- Ввод: 2 стика + кнопки действий + настройка чувствительности/прозрачности.
- Gamepad: InputMap «joy_*», переназначение.
- Haptics через `Input.vibrate_handheld`.

### Локализация
- JSON по языкам с ключами, автопроверка тестами.
- Шрифт: Manrope (OFL) + Noto Sans fallback, кириллица.

### Измеримые критерии
- Запуск <10с на эмуляторе, <15с на устройстве.
- 30 FPS Medium на эталоне Snapdragon 778G (цель, измеряется benchmark сценой).
- Память <1.2 ГБ в профиле.
- APK <120 МБ (debug).
- Тесты ≥95% проходят.

## 3. Этапы

1. **Scaffold (день 1):** project.godot, export_presets, CI, локализация, чанк-система, базовый мешинг.
2. **Core loop (день 1-2):** игрок, управление, инструменты, взрыв, огонь, физика-предметы.
3. **Контент (день 2):** 3 локации, 4 миссии, обучение, песочница, UI.
4. **Оптимизация (день 3):** бюджеты, pooling, LOD, benchmark, профили.
5. **Android & polish (день 3):** touch, safe area, пауза, сохранение, haptics, gamepad.
6. **QA & Release (день 3):** тесты, clean build, APK, Release, SHA256.

## 4. Риски
- Heavy meshing в main thread → пофреймовый бюджет.
- Android Vulkan нестабилен → fallback.
- Нет физического девайса → честность отчётов, benchmark сцена.

## 5. Definition of Done
- Клонируется и собирается.
- CI зелёный.
- APK устанавливается и запускается.
- 4 миссии + обучение + песочница.
- Разрушения/сохранения/touch работают.
- Русская локализация 100%.
- Release с checksum.
